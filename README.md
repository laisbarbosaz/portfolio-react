
## Estrutura
- `src/dados.js` – todos os dados do site (perfil, experiência, projetos, stacks, formação)
- `src/App.jsx` – monta a página com as seções
- `src/components/` – um componente por parte da página (Menu, Abertura, MatrizRisco, etc.)
- `src/index.css` – estilos

## Como rodar
```
npm install
npm run dev
```
Abra o endereço mostrado no terminal (normalmente http://localhost:5173).
